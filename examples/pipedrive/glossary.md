# Glossary

| Term | Definition | Evidence |
|---|---|---|
| Pipeline | An ordered list of stages a deal moves through. A company has several; the board shows one at a time | [obs EV-008] [doc SRC-004] |
| Stage | A column of a pipeline with a name, a win probability (0-100%) and an optional rotting period | [obs EV-008] [net EV-009] |
| Deal | A sales opportunity with a title, value, owner, stage and status (open, won, lost), linked to a person or an organization | [obs EV-027] [net EV-009] |
| Board (pipeline view) | The kanban screen: one column per stage, one card per open deal | [obs EV-011] |
| Activity | A dated task linked to a deal, organization or person, with a type, an owner and a done flag | [obs EV-019] [net EV-009] |
| Activity type | A company-defined list of kinds of activity (call, task, custom types) with icons; its order decides the default type | [obs EV-022] [net EV-025] |
| Next activity | The earliest open activity of a deal; it drives the card icon and the board order | [obs EV-010] [doc SRC-002] |
| Activity status icon | The round icon on a card: red overdue, green today, grey future, yellow warning when the deal has no open activity | [obs EV-012] [obs EV-013] [obs EV-014] [obs EV-015] |
| Schedule your next activity | The modal that opens when the last open activity of a deal is marked done | [obs EV-022] |
| Focus | The deal page block that lists open activities and pinned notes | [obs EV-027] [obs EV-058] |
| History | The deal page timeline of done activities, notes and changes, with filters | [obs EV-030] |
| Stage bar | The chevron bar on the deal page that shows days per stage and moves the deal on click | [obs EV-028] [obs EV-032] |
| Won / Lost | The two closing statuses of a deal; both can be reopened | [obs EV-035] [obs EV-042] [obs EV-037] |
| Lost reason | The required reason when a deal is lost, picked from a company list | [obs EV-039] [obs EV-040] |
| Rotting | A per-stage period after which an inactive deal is marked: pink card and a red "<Nd" badge | [obs EV-016] [doc SRC-005] |
| Weighted value | Value × probability; the stage header sums it for its deals | [obs EV-010] [doc SRC-006] |
| Visibility (visible to) | Who can see an item: item owner, owner's visibility group, group and sub-groups, all users | [obs EV-052] |
| Visibility group | A company-level group of users that decides which pipelines and items they see | [doc SRC-041] |
| Follower | A user who follows a deal; the owner follows by default and followers can see owner-only items | [obs EV-052] |
| Restore data | The settings page that keeps deleted items for 30 days | [doc SRC-015] [obs EV-045] |
| Quick add | The "+" menu in the top bar with one-key shortcuts for new items | [obs EV-055] |
