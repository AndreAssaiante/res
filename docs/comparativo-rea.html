reverse-engineering-saas vs REA

Duas ferramentas de engenharia reversa. Cada uma responde uma pergunta diferente. Base: teste do REA no ClickUp, 15/10/2026.

REA Com que tecnologia o produto foi feito? Stack, módulos, API, feature flags, binários. Ótimo para auditoria técnica.
Nossa skill Como o produto funciona, e como reconstruí-lo? Telas, estados, regras, modelo de dados, design. Sem mexer na produção.

Outros diferenciais

Registra cada mudançaLivro de alterações com o valor anterior e o jeito de desfazer. Limpeza no fim.
Escritas escondidasAutosave, notificação lida, banner fechado e view salva contam como alteração.
Regras viram testesCada regra observada vira um teste de paridade para o clone.
Evidência em tudoCada afirmação cita print, rede ou doc. Um verificador acusa o que falta.
Continua de onde parouSTATUS.md, log por sessão e fila de cobertura. Nenhuma memória fica só no chat.
Leve5 scripts sem dependência. O REA gasta ~110 mil tokens só para carregar as ferramentas.
